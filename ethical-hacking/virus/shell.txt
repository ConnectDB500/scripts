Abrir os arquivos:
start explorer

Abrir a configuracao do sistema:
start msconfig

abrir o site do google:
start www.google.com

Abrir um site aleatorio:
start www.aleatorio.com

Criar um diretorio "pasta":
md pasta

Criar um arquivo "texte.txt":
dir >> teste.txt

Reiniciar o computador em 10s:
shutdown -r -t 10 

Desligar o computador em 10s:
shutdown -s -t 10 

Exibir o conteudo de um arquivo:
type arquivo.txt

Criar um arquivo vazio:
type nul > arquivo.txt

Mostra o diretorio atual:
cd

Mover o arquivo "origem.txt" para o "destino.txt":
move origem.txt C:\outra\pasta\

Renomear o arquivo "antigo.txt" para "novo.txt"
move "antigo.txt" "novo.txt"
