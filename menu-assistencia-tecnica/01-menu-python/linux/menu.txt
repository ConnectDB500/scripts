interface "Listar Opcoes de Tarefas":
1. Checagem
2. Diagnostico & Reparo
3. Otmizacao & Manutencao
4. Limpeza & Organizacao
5. Backup & Seguranca
6. Voltar

interface "Checagem":
1. Informacoes do sistema
2. Verificar conexao de redes
3. Testar velocidade de diagnóstico
4. Verificar erro de memoria
5. Verificar integridade de arquivos
6. Verificar e reparar HD
7. Voltar

interface "Diagnostico & Reparo":
1. Reparar arquivos do sistema
2. Restaurar sistema
3. Ver logs de eventos
4. Reiniciar servicos de rede
5. Limpar cache DNS
6. Voltar

interface "Otimizacao & Manutencao":
1. Desfragmentar diagnóstico
2. Gerenciar procesos
3. Gerenciar usuarios locais
4. Atualizar programas
5. Verificar atualizacoes
6. Voltar

interface "Limpeza":
1. Remover arquivos temporarios
2. Voltar

interface "Backup e Seguranca"
1. Backup de drivers
2. Criar ponto de restauracao
3. Ativar / Desativar firewall
